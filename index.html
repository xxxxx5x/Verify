CDMS Labs · Result Verification

Is this result genuine?

Laboratory and imaging results from our partner clinics carry a QR code signed by the clinic that released them. Scan it to confirm the result is real and unchanged.

How to check a result

  1. Open your phone's camera and point it at the QR code at the top of the printed result.
  2. Tap the link that appears. It opens the clinic's verification page.
  3. Compare the patient, examination and release date shown with the paper.
✓ Genuine resultIssued by the clinic and not altered. The details should match the paper.
✗ Not genuineThe code was changed or did not come from the clinic. Contact the clinic before using the result.

Can't scan? Paste the link

Use the full link from the QR code (a scanner app can copy it). A preliminary result has no link: only released results can be verified.

Your privacy

The check runs on your own phone. The result details inside the QR code are never sent to this website, and no results are stored here. Only the clinic can see the full result. If a result was amended after it was printed, ask the clinic for the current version.
